# HopefulSpace · 盼头空间 🌿

面向 ENFP / P 型人格的**柔性灵感 & 生活管理工具**（纯前端 Web 原型）。

> 可以标记目标锚点日期（俗称 DDL）和粗略时间，工具会给一点**仅供参考**的计划提示；
> 但这绝对不是一个内卷 / 催促型待办 APP —— 没有自动倒计时、没有红色警告、没有自动"逾期"状态。
> 计划永远可以搁置、修改、放弃，这一切都是正常的。

---

## 核心哲学

- 用 **「目标锚点日期」** 代替「DDL / 截止日期」：日期只是你心里想抵达的记号，不是审判。
- 所有时间推算提示都带着这句话：**「✨仅作参考，不必照做，节奏由你掌握」**。
- 不制造焦虑、不计算 KPI、不搞连续打卡 —— 记录是为了看见日子，不是比赛。

## 功能一览

| 页面 | 功能 |
|---|---|
| 🏠 首页 · 我的小盼头看板 | 随机治愈欢迎语、柔和统计卡（只显示数量）、今日小收获快照（随机抽取近 30 天的一条记录）、💾 导出备份 |
| 📁 我的项目集 | 新建项目（内置图标 + 内置柔和颜色）、归档 / 移出归档、删除（只摘除关联，不删下属数据）、项目详情页看关联笔记 |
| 📝 灵感笔记 | 增删改查、允许无标题碎片、最多 2 个心情标签、可选关联项目、关键词搜索 |
| ✨ 轻松打卡 | 打卡事项 + 打卡浮层（🥳/☁️/✨/😌 四选一心情，可跳过）+ 30 天日历视图，空白格子无负面标记 |
| 🌿 近期期待 · 时间地图 | 可选锚点日期 / 预估时长（固定下拉）/ 氛围标签 / 关联项目；条目内生成"仅供参考"的开始日期提示；月历只在锚点日画半透明圆点；默认按最新创建排序，可手动切换 |
| 💬 AI 灵感聊天 | 本地模拟对话（**预留 AI 扩展 · 当前仅演示**），新建 / 删除对话，绝不调用任何真实 API |

## 技术栈

- Vite + React 18（JSX，无 TypeScript）
- react-router-dom v6（HashRouter：部署到任何静态托管都不用配置服务器）
- Tailwind CSS v3（自定义柔和色板：奶白 / 淡紫 / 浅薄荷 / 暖金 / 雾蓝）
- 浏览器内数据库：IndexedDB（开源封装库 [Dexie.js](https://github.com/dexie/Dexie.js)）——纯前端本地库，不是服务器数据库，不上云

## 本地运行

```bash
npm install    # 第一次执行即可
npm run dev    # 启动开发服务器，浏览器打开 http://localhost:5173
npm run build  # 打包到 dist/，用 npm run preview 预览
```

## 数据与存储

- 数据存放在浏览器自带的 **IndexedDB** 数据库（由开源库 [Dexie.js](https://github.com/dexie/Dexie.js) 封装），容量远超 localStorage（数百 MB），**仍然纯前端、只在本机、不上云**。
- 刷新 / 关掉再开都不丢；启动时自动把早期 localStorage 里的旧数据迁移进库（旧数据保留不动，不删除）。
- 兜底机制：IndexedDB 不可用（例如无痕模式下被禁用）时自动回退 localStorage 保存（页面下方已注明「别用无痕模式当正常使用方式」）。
- 核心 5 组 + 聊天附加 2 组（字段按约定模型，ID 统一前缀，日期存 ISO 字符串 / `YYYY-MM-DD` 文本）：
  - `hopefulspace_projects`：`proj_` 前缀（isArchived 表示归档，不等于删除）
  - `hopefulspace_notes`：`note_` 前缀（projectId 为 null 表示自由灵感）
  - `hopefulspace_checkitems`：`checkitem_` 前缀（打卡事项）
  - `hopefulspace_checklogs`：`checklog_` 前缀（单次打卡记录，moodEmoji / projectId 可空）
  - `hopefulspace_hopes`：`hope_` 前缀（status 只有 expecting / done / shelved，**绝无逾期**）
  - `hopefulspace_chats` / `hopefulspace_chatmessages`：聊天对话与消息（原型演示用）
- 建议开始日期**只在页面运行时临时计算**，不存进数据，方便以后随时调整算法。
- 备份：首页「💾 导出我的数据备份」把全部数据下载为 `hopefulspace_backup_日期.json`（MVP 只做导出，不做导入）。

## 使用建议（也是产品哲学）

- 项目是**虚拟文件夹**，只在应用内做逻辑整理，不碰你电脑里的真实文件。
- 归档、搁置、放弃都是正常操作，系统永远不给负面评价。
- 心情标签、锚点日期、预估时长 —— 全部选填，留空也是一种安排。
